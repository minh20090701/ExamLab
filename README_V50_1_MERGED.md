# ExamLab V50.1 + bản sửa tự tải đề Admin

Bản cộng dồn áp dụng trên V49.1 hoặc V50/V50.1. Giữ đủ 20 chủ đề chung, bỏ giao diện cá nhân, sửa tương phản và thanh thông báo V50.1; tích hợp nguyên mã js/admin.js của bản vá V49.1 tự tải đề admin, cùng các thành phần HTML cần thiết.

1. Nếu chưa chạy SQL V50, chạy docs/SETUP_GLOBAL_THEMES_V50.sql trong Supabase SQL Editor. Không cần SQL thêm cho bản sửa admin.
2. Upload ZIP vào thư mục gốc Codespaces rồi giải nén đè, xóa ZIP, commit và push main.
3. Sau khi GitHub Pages deploy, Ctrl+F5.

Kiểm tra: mở quản đề, danh sách và nội dung đề phải tải mới từ máy chủ; thử làm mới, mở bản nháp, sửa/lưu/xuất bản cùng mã đề; kiểm tra kho 20 chủ đề chung. Bản nháp chưa xuất bản vẫn lưu trên thiết bị. Không kiểm thử Supabase thật trong lần ghép này.
